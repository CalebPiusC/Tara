# ADR-0013: Gemini Live is the primary voice engine; local models are dormant
**Status:** Accepted by the owner's direction on 2026-10-20 (implementation unverified against the live service)
**Context:** the owner has a Gemini API key and wants a simpler voice pipeline. Docs (L1-L8) show Live supports 16 kHz PCM in, 24 kHz PCM out, transcription, server VAD with barge-in, function calling, session resumption and context compression. **Options:** keep the cascaded Whisper+Qwen+Kokoro path; Gemini Live primary; both. **Decision:** Gemini Live behind our own interfaces (`voice/events.py`); our code owns participation gating, playback cancellation, tools and memory; no local model is downloaded or started; local adapters stay as optional code. **Reasons:** fewer moving parts and no model downloads; interruption and turn-taking come from the provider; interfaces keep alternatives possible. **Consequences:** audio and transcripts go to Google (consent, paid tier needed for real interviews); the model answers whatever it hears so delivery must be gated by us; we cannot cancel server generation; cost per audio minute. **Risks:** unverified real behavior (event ordering, latency, model access); provider limits (15 min audio-only without compression, about 10 min connections); vendor lock-in limited to one file. **Evidence:** official docs and SDK inspection only, no live run. **Validation:** smoke test and opt-in integration test with a real key, then measured latency and interruption behavior.
