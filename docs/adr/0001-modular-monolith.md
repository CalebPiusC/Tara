# ADR-0001: Modular monolith
**Status:** Proposed
**Context:** Local-first, hackathon timeline, one machine. **Problem:** how to structure services. **Options:** microservices; modular monolith with worker pool; notebook/script. **Decision:** one Python process, typed protocols, worker threads/processes for inference. **Reasons:** simplest debuggable cancellation and shared state. **Consequences:** inference crashes must be isolated by worker supervision. **Risks:** CPU contention on one machine. **Evidence:** reasoning only ([REAL_TIME_ARCHITECTURE_RESEARCH.md](../REAL_TIME_ARCHITECTURE_RESEARCH.md)); repo is empty. **Validation:** latency harness in Phase 2; split a worker out only if measured.
