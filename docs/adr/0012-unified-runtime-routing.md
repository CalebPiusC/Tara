# ADR-0012: Unified runtime with rule-bounded routing and cloud escalation
**Status:** Proposed
**Context:** three small local models plus an optional cloud model must behave as one system on a laptop and later on constrained devices. **Options:** merge models (rejected: out of scope, no basis); microservice per model; one process with bounded pools and typed interfaces; let the small model route freely. **Decision:** one process; rules define allowed routes and Qwen may only choose among them; escalation to Gemini with a minimal payload on failure, low confidence or ungrounded answers; side effects only after runtime approval. **Reasons:** a 0.6B model cannot be trusted with permissions; simplest to cancel and measure. **Consequences:** keyword rules will misroute some questions; self-reported confidence may be poorly calibrated. **Risks:** memory pressure with all models loaded; Qwen quality unknown. **Evidence:** model cards only (Qwen3-0.6B, mlx-lm); no measurements. **Validation:** Phase 2 benchmarks and a routing eval set.
